# AS2 EDU + Piper-H 装配依据

历史默认模型是早期研究仿真假设：`configs/as2_piper.json` 将 `piper_base_link` 以 `xyz=[0,0,0.12]`、零旋转直接固定到 `base_link`，安装件无质量。它没有还原背部导轨和转接板，不能作为真实 AS2 EDU + Piper-H 装配。历史模型与实验保留此定义以便复现；现已另外构建带官方导轨和本页拟定转接板的候选资产，保留历史默认定义；候选仍不是实物标定。

实际装配链应为：**AS2 机身 → 背部导轨 → 匹配的固定件/转接板 → Piper-H 底座**。源 AS2 URDF 没有独立导轨 frame；Piper-H 首关节的源模型高度也不是转接板高度。

## 官方 AS2 背部接口

2026-09-13 实际读取用户提供的[宇树《关于 As2》手册](https://support.unitree.com/home/zh/AS2_SDK_Development_Guide/about_as2)，页面标注更新于 2026-09-02。在“部件名称”下找到并视觉读取了[背部负载安装孔位图，单位 mm](https://doc-cdn.unitree.com/static/2026/6/25/0ad8b87e21b4418c8198dc98f1b72c23_1245x470.png)。之前仅凭源 URDF/产品页未找到安装图，不能据此说官方未提供接口尺寸。

| 图中明确标注 | 尺寸 |
|---|---:|
| 两轨孔中心线间距 | 152 mm |
| 单轨纵向长度 | 140 mm |
| 纵向孔距及端距 | 10 + 60 + 60 + 10 mm |
| 截面外宽 / 最大高度 | 20 / 18 mm |
| 槽开口 / 槽内宽 | 6 / 10 mm |

完整槽形以原图为准，不能仅凭上述尺寸选择螺纹规格或紧固力矩。截面 18 mm 是导轨自身尺寸，**不是** `base_link` 到安装面的高度。该图没有建立导轨与当前 URDF `base_link` 的完整坐标关系，也没有给出 Piper-H 转接板。

该手册 EDU 栏还确认带电池约20 kg、持续行走负载约15 kg；这些整机规格不能替代具体伸展姿态下的安装件载荷验算，也不能确定源模型缺失质量的位置。

随后实际读取[获取SDK与开发资源](https://support.unitree.com/home/zh/AS2_SDK_Development_Guide/get_sdk)：该页明确提供含尺寸与安装导轨信息的[As2/As2W简化模型包](https://oss-global-cdn.unitree.com/static/18f58899d6484f08839890ea5c9d6bec.zip)。已核实包内足端和轮足STEP分开，其中`AS2简化模型（足端）0901.stp`为本次对象；不能继续把旧URDF缺少导轨frame等同于没有官方机械模型。本次已进一步将足端STEP中的机身解析平面与固定URDF机身STL配准，并提取两根导轨，结果如下。

### 官方足端CAD到当前URDF的坐标注册

以机身5个解析平面求解满秩刚性变换，并用另10个平面检查；平面均值的最大残差为1.234e-5 mm。这支持指定平面和坐标基准对应，未证明两份简化模型的全部表面一致或实物尺寸已校准。

提取导轨上接触平面后，两轨中点O在`base_link`中约为`[-5.000003, -0.000001, 86.254551] mm`，三轴平行。实际导轨中心间距152 mm，长度140 mm；STEP的斜底面使最大高度约17.756 mm，不强行改成手册的取整18 mm。导出的两份STL顶点已在`base_link`米制坐标下，资产中采用零origin，不能再次叠加导轨位姿。

来源ZIP SHA256为`e6ec3c320f8dfa9463862de13f90fb0a63e0c90ed601955f11f4a57d80bd75ed`，足端STEP SHA256为`1f795d5784673e1488a00713240ee67fd247a0f1e7823cb73e64561c41d3b35d`。解析脚本、平面证据、矩阵和导轨网格保存在本地`outputs/as2-rail-frame-audit-20260913/`。

## 官方 Piper-H 安装接口与负载曲线

用户提供的[松灵手册](https://agilexsupport.yuque.com/staff-hso6mo/alxgtf/ay1awrn2hrhn1krg?singleDoc)明确标为 **PIPER H**，本次读取内容标注更新于2026-08-11。2.4.1节文字给出底座四个M5螺纹通孔、70×70 mm孔距；[对应安装原图](https://cdn.nlark.com/yuque/0/2025/png/33709157/1767175387998-59ffc4b5-8070-4a90-8e1e-bfc62c6f6efe.png)给出80×95 mm外形、70×70 mm四孔，但孔标注为“φ5.4贯穿”。孔距可以作为布局依据，文字与图的螺纹/间隙孔差异须确认对应零件，不能据此直接确定加工和紧固规格。此前未确认普通Piper尺寸是否适用H的缺口，现由这份明确H手册补足。

2.3节提供[机械臂末端负载曲线](https://cdn.nlark.com/yuque/0/2026/png/29291030/1769355605793-4eaabd51-7c61-4ed5-86f7-593e45b9b6f4.png)，横轴L(mm)、纵轴Z(mm)，2 kg曲线在横轴上的读数为500 mm。但图和相邻正文没有定义L/Z参考原点、末端姿态、负载COM或动态条件。**不能把500 mm当成base到TCP的工作半径，也不能当成负载质心偏距**，因此不能由该数值与636.65 mm工作半径的大小关系判定满伸展2 kg允许或不允许。当前2 kg点质量候选仍只是仿真压力条件，不能标成厂商认证的全伸展负载域。

同册的[H模型文件页](https://agilexsupport.yuque.com/staff-hso6mo/alxgtf/glzd7a853owrmsk0)列出“PIPER-H外发.tar”；本次未取得可核验的归档内容，未以它认定底座坐标或孔的加工定义。

### 固定Piper-H网格已确认的安装坐标

进一步读取固定版本`f6642ce0d7872c686f29c99e9e10cd23d1d49313`的[官方视觉base_link.dae](https://raw.githubusercontent.com/agilexrobotics/agx_arm_urdf/f6642ce0d7872c686f29c99e9e10cd23d1d49313/piper_h/meshes/dae/base_link.dae)，并与已有碰撞STL核对。两者均12440个三角面，双向顶点差最大1.014e-7 m；URDF视觉/碰撞变换均为零，无缩放。

网格中存在z≈0的大面积共面底面，以及从z=0贯穿至4 mm的四孔内壁。多高度切片、孔心轴线与邻近实体射线求交共同支持安装底面位于源Piper `base_link` 的z=0，结论并非只取包围盒最低点。四孔中心为`(-40,±35)`和`(30,±35)` mm；孔阵列中心为`[-5,0,0]` mm。实际板轮廓为x=[−55,40]、y=[−40,40] mm，即95×80 mm，不能用带接插件突出部分的整mesh包围盒替代。

定义H为孔阵列中心、三轴平行于Piper源坐标P，则`T(P←H)=translation([-0.005,0,0]) m`，反向为`T(H←P)=translation([+0.005,0,0]) m`。这补足了固定模型的孔阵列到底座原点关系；实物版本和手册孔型差异仍未校准。完整脚本、切片和来源SHA位于本地`outputs/as2-mount-frame-audit-20260913/`。

## 第一版安装布局候选

当前尚未选购转接板，先采用**可拆卸的双导轨横跨板，Piper孔阵列左右居中、纵向对齐导轨中点**作为布局候选。沿轨位置以后按机械臂工作区、整机COM和附件空间调整；本候选尚未替换运行中的历史资产。

![双导轨横跨板布局候选](as2-mount-layout.svg)

设O位于两轨纵向中点之间、导轨上接触面的中心，X向机器人前方，Y向左，Z向上。下表除厂商孔距外均为本次设计选择；紧固点位置不代表已确定孔型或螺纹规格。

| 项目 | 首版候选 |
|---|---|
| 板件尺寸 X×Y×Z | 160×180×6 mm；6 mm尚未进行载荷/刚度验证 |
| 导轨侧四个固定点 X/Y | (±50, ±76) mm；采用匹配实际槽型的固定件，避开原导轨固定螺钉 |
| Piper侧四孔中心 X/Y | (±35, ±35) mm，对应官方70×70 mm孔阵列 |
| 机械臂朝向 | 候选选择Piper源+X朝机器人+X，三轴平行；实物接插件和运动间隙另行核对 |
| 板材密度计算假设 | 2700 kg/m³，具体铝材和固定件尚未选定 |
| 未开孔板质量 / COM相对O | 0.46656 kg / [0,0,3] mm，不含螺钉、滑块、线缆 |
| 板自身COM处惯量 Ixx/Iyy/Izz | 0.00126111168 / 0.00099672768 / 0.00225504 kg·m²，积惯量为0 |

质量由`ρ×长×宽×厚`计算，惯量使用均匀长方体公式。开孔和紧固件选定后重新计算，不能把该板质量当作全部缺失附件质量，也不能用它解释源AS2与EDU标称20 kg的差额。

Piper安装图本身没有把φ72圆心命名为URDF原点；本次依据上述独立网格切片补入源底板外形。孔阵列中心位于O的正上方6 mm，Piper源原点相对O为`[5,0,6]` mm，旋转按候选轴平行。装配变换为`T(base←Piper)=T(base←O)·T(O←H)·T(H←Piper)`；两侧模型基准现已核对，得到Piper源原点在AS2 `base_link`中约为`[0,0,92.254551] mm`，零旋转；比旧安装假设低27.745449 mm。

这版确定的是布局和模型坐标链。仍需检查电池取出通道、雷达、机械臂完整运动和线缆空间；实物装配还需确认型号和紧固件，再验证板件与连接在相应姿态/动态载荷下的承载。原始计算和PNG预览保存在本地`outputs/as2-mount-layout-20260913/`。

### 用于设计的静态重力工况

对已有源默认姿态和先前几何伸展候选，以URDF FK计算各Piper刚体COM，求`Σ(r×mg)`；没有物理积分或优化器更新。以下力矩以Piper源原点为参考，重力为9.81 m/s²，机械臂及固定夹爪合计4.707 kg。

| 姿态 | TCP额外点质量 | Piper底座处静态弯矩幅值 |
|---|---:|---:|
| 源默认姿态 | 0 kg | 1.3761 N·m |
| 源默认姿态 | 2 kg | 8.3769 N·m |
| 先前几何伸展候选 | 0 kg | 12.5155 N·m |
| 先前几何伸展候选 | 2 kg | 27.8293 N·m |

最后一项沿本候选变换到O，计入板自重，竖直载荷为70.3726 N，弯矩约28.1583 N·m。在“刚性板、四个等竖向刚度支点”的理想分配下，前侧两点各约158.4 N受压，后侧两点各需约123.2 N向下拉住板件；四点力与力矩平衡残差小于1e-10。这说明连接设计需要考虑力矩及抬起趋势，不能只用总重量除以四。该分配不是实际螺栓拉力预测，未计预紧、接触、板件柔度或动态载荷，也不证明6 mm板通过承载验证。伸展姿态仍只是未经碰撞/执行器可行性验证的几何候选，2 kg仍不是满伸展额定能力声明。

可复跑计算为本地`outputs/as2-mount-layout-20260913/gravity_loads.py`，`gravity-loads.json`保存各体力矩、姿态、输入SHA及平衡残差。

## 新装配候选资产及证据边界

本地`outputs/as2-rail-mounted-candidate-20260913/assembly.json`明确选择上述装配，使用`--nominal-config`生成独立资产族。新增两个真实导轨网格与一个转接板box，板质量及COM惯量合入机身，保持28个物理体、18个控制关节；碰撞形状由42增至45。没有额外添加导轨质量：源AS2本体惯量是否已包含导轨无法拆分，当前假定包含，避免重复计入。

名义整机质量为22.81356 kg；AS2本体密度调至20 kg并加TCP 2 kg点质量时为27.17356 kg。板始终保持0.46656 kg，AS2密度随机化只作用于原AS2部分。实际六个MuJoCo模型均已加载，FK最大位置误差3.08e-7 m、惯量张量最大误差4.11e-8 kg·m²；这些静态构建检查没有积分物理或执行学习；随后官方Lab六环境和MuJoCo两个短工况也完成有界实际消费，见[预训练候选的消费证据](as2-pretraining-family.md)。

静态凸几何诊断检查源默认姿态和源关节限位35%/65%处的三个姿态：没有发现板/双轨与Piper之间内切半径超过1 µm的体积重叠；板与Piper底面、导轨顶面在约1e-9 m舍入范围内接触。板底高于原机身box顶10.25455 mm。该有限姿态检查不能替代完整运动范围、引擎接触或实物间隙验证。记录为候选目录的`geometry-check.json`及`family-verification.json`。

## 实物装配仍需确定

1. 实物AS2与固定CAD/URDF的版本和坐标基准对应。
2. Piper-H实物版本与70×70 mm孔阵列的螺纹/间隙孔关系。
3. 最终转接板、槽内固定件、螺钉和线缆的尺寸、实际质量与空间；板件与连接的静态/动态承载及拆装通道。

当前已具备候选装配的资产生成路径，后续训练和评估必须记录所选配置身份。旧0.12 m模型的历史消费结果仍只适用于旧资产；新装配的仿真消费与学习结果须分别报告。
